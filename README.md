# FUNCIBERENEJUN2025
Este es el repositorio de la materia de Fundamentos de Ciberseguridad


## Estructura del Repositorio

1. En 'ActividadesPorTema' estan las actividades que se realizaran a lo largo del curso en formato yaml, en cada uno de ellos estan los reactivos, cada reactivo es una calificación.
2. En 'Tema1', 'Tema2', 'Team3' y 'Tema4'. Ahi deben crear una carpeta con el siguiente formato [numeroControl]_[numeroControl], ejemplo 08590312_08590312.
3. En 'Equipos' aqui deben colocar sus definiciones de equipo,el archivo se debe llamar igual que sus carpetas, si su color es rojo entonces el archivo debe llamarse rojo.yaml se incluye un ejemplo.

## Notas
* En esta materia se require un dispositivo microcontrolador como Esp8266 o Esp32
* Tambien es necesario usar un proveedor como los es vultr o digital ocean 
* Es posible que tengan que crear una cuenta de paypal y adjuntar una tarjeta de debito para realizar el pago del proveedor mencionado
* Aproximadamente se requieren 6 USD
